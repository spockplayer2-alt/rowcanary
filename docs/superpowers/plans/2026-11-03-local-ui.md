# Local browser UI implementation plan

Goal: deliver the roadmap's loopback-only UI for generation, upload/check and
report downloads, reusing the exact core and v0.3.0 reports.

Architecture: standard-library HTTPServer bound to 127.0.0.1; packaged HTML,
CSS, JS and existing icon. JSON/base64 requests keep binary XLSX exact without
adding multipart libraries. One request at a time, bounded bodies and temporary
files discarded after each operation. No hosted service or external resources.

Ruling: select the standard library over a new framework because this is a
single-user local tool with two operations; the cost is no production hosting.
Ruling: preserve the existing canary icon and identity; use system fonts and
accessible light/dark themes without external assets.

Review focus: rebinding Host, cross-origin POST, missing token, oversized or
truncated HTTP bodies, hostile filenames, exact CRLF and formula literals,
installed-wheel static assets, keyboard navigation and narrow viewports.

1. Tests first in tests/test_web.py: real ephemeral HTTP server, security
   headers/Host/Origin/token boundaries, generate/check across five formats,
   malformed/oversized uploads and schema-consistent failures. Observe RED.
2. Implement rowcanary/web.py make_server(port=0) and serve(port=8765), with
   fixed static routes, fresh random per-server token, JSON 4xx errors, safe
   filenames and no filesystem paths from browser input. CLI serve --port and
   optional --open; reject unsupported binds and invalid ports.
3. Packaged rowcanary/static/{index.html,app.css,app.js,icon.svg}; step-based
   workflow, labeled format/probes/encoding/delimiter, custom controls, upload,
   strict order, textContent diagnostics, JSON/HTML download, no external fetch.
4. Run focused tests then real browser generation/upload/differences/download,
   keyboard/theme/mobile checks and screenshots. Add targeted regressions for
   failures, then full suite, Ruff, dependency/package/install/asset gates.
5. Independent review of the milestone; fix important findings with RED/GREEN.
   Document actual behavior and security limits; update PROGRESS and changelog.
6. trail check, commit/push, all 17 CI jobs; publish/verify v0.4.0 attachments.

Acceptance: core behavior and default controls unchanged; no external resource,
arbitrary file read/write, public bind or unauthenticated mutation endpoint.
