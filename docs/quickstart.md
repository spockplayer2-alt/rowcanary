# Your first real control check

1. Install from [PyPI](https://pypi.org/project/rowcanary/) with
   `python -m pip install rowcanary`. Requires Python 3.10 or newer.
2. Start `python -m rowcanary serve --open`. Keep the terminal running.
   Choose **Generate controls**, a file format and a control set. Download the file.
3. In a disposable workspace in your target application, import and export that
   file. Keep both control columns. Never mix controls into production records.
4. Select **Check your export**, choose the returned file and use the same
   control set/custom values. Match the exported delimiter and renamed columns.
   Leave encoding blank for BOM-aware input. Download JSON or HTML to retain evidence.
5. Stop the local server with Ctrl+C when finished.

For terminals, the same workflow is:

```console
python -m rowcanary make controls.csv
python -m rowcanary check exported.csv --report result.html
```

`PASS` means every control and required structure matched. `FAIL` identifies
observed differences. A malformed file is an error, not a failed integrity
comparison. Duplicates/extra rows can fail even when all 24 values survived;
use the PASS/FAIL status, not just the count. A pass covers the controls only.

## Spreadsheet workflows

CSV quoting does not stop formula evaluation. Import formula-like controls as
literal text using the application's explicit import settings. Do not double
click a CSV expecting type preservation. Native Excel profiles recorded in
[compatibility](compatibility.md) changed line breaks even with text columns;
automatic inference additionally changed numbers, IDs and formula-like text.
These are real findings; RowCanary must report them rather than normalize them.

When supported, try XLSX generated by RowCanary: text controls are stored as
literal string cells, including formula-like controls, without formula elements.
The file itself retains CR/LF exactly. This does not promise Excel or another
application will preserve values after editing/exporting. Check the actual
returned file. JSON/JSONL are alternatives for systems that support native types.
Do not add apostrophes, strip spaces or replace line breaks to obtain a pass.

## Common problems

- **Missing column:** inspect the export headers and set the ID/value names in
  Advanced settings or `--id-column`/`--value-column`.
- **Everything is missing:** use the same control set/custom JSON and ensure
  the export includes both columns and every control row.
- **Wrong separator/encoding:** select the application's export delimiter;
  use an explicit legacy encoding only when known. UTF BOMs are detected by default.
- **Cannot create a file/report:** outputs never overwrite; choose a new name.
- **Port in use:** run `python -m rowcanary serve --port 0 --open`.
- **Command not found:** use `python -m rowcanary` from the Python installation
  where the wheel was installed.
